# Browser Assistant

Расширение для Chromium-браузеров (Manifest V3), которое собрало в одном месте
четыре независимых инструмента:

1. **Память вкладок** — список открытых вкладок с расходом памяти, бейдж на иконке
   расширения, закрытие вкладки кликом по названию.
2. **Экстрактор ссылок** — сбор ссылок со страницы с фильтром по расширениям файлов
   (pdf, zip, exe, …) и копированием результата в буфер.
3. **Баллы (VK Video Live / Twitch)** — автосбор наград канала на `live.vkvideo.ru`
   через API и клик по бонусным кнопкам Twitch прямо в DOM, со страницей статистики.
4. **Анонимайзер** — подмена заголовков и браузерных отпечатков: постоянный режим для
   выбранных сайтов и временный профиль страны для отдельной вкладки.

Чистый JavaScript без сборки и зависимостей: модули ES, сервис-воркер, никаких
транспайлеров.

## Установка

1. Откройте страницу расширений вашего браузера:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Opera: `opera://extensions/`
   - Brave: `brave://extensions/`
   - Yandex: `browser://extensions/`
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку проекта.
4. Иконка появится рядом с адресной строкой.

> Требуется Chrome 110+ (используется `chrome.processes` и API MV3).

## Возможности

### Вкладки
- Расход памяти по каждой вкладке через `chrome.processes` (точная оценка по процессам
  Chrome); если API недоступен — приблизительный замер через JS-heap (`performance.memory`).
- Бейдж на иконке: суммарная память (зелёный / жёлтый ≥ 1 ГБ / красный ≥ 4 ГБ),
  либо счётчик собранных баллов — переключается в настройках.
- Клик по названию вкладки закрывает её; кнопка `↗` переходит на вкладку.
- Метки окон (`О1`, `О2`) при нескольких окнах, favicon, URL.

### Ссылки
- Сбор всех `<a>`/`<area>` активной вкладки через `chrome.scripting.executeScript`.
- Фильтр по списку расширений (настраивается) или «все ссылки».
- Копирование найденных URL в буфер одной кнопкой.

### Баллы (VK Video Live / Twitch)
- **VK Video Live (API)**: сбор ожидающих бонусов по каналам, на которые вы подписаны.
- **Twitch (DOM)**: `MutationObserver` + резервный интервал, защита от двойного клика.
- Токен VK перехватывается из `Authorization` исходящих запросов (`webRequest.onSendHeaders`)
  и/или из `localStorage` страницы; **хранится только в памяти**, короткие ротации
  обрабатываются тихо.
- Watchdog через `chrome.alarms` будит сервис-воркер раз в минуту и догоняет пропущенный
  сбор, перевнедряет content-скрипт в уже открытые вкладки.
- Страница статистики: итоги, графики по каналам и времени, фильтры (платформа/период/канал),
  экспорт CSV/JSON, ручной бэкап/восстановление, авто-бэкап в «Загрузки».

### Анонимайзер
- **Постоянный режим (по сайту)**: заголовки через `declarativeNetRequest` (`modifyHeaders`) —
  подмена `User-Agent`, `Accept-Language`, удаление `Referer` и `sec-ch-ua-*`/`Client Hints`.
- **Отпечатки (MAIN world)**: инъекция скрипта в страницу — `navigator` (язык, платформа,
  ядра, `deviceMemory`, `userAgentData`), canvas-шум, WebGL vendor/renderer, часовой пояс/`Intl`.
- **Временный профиль вкладки**: страна/локаль/таймзона из пресета (`anon-profiles.js`),
  опционально подмена экрана, геолокации и блокировка WebRTC; действует до закрытия вкладки.
- Анонимайзер **не скрывает IP** — за выходной адрес отвечает прокси/VPN.

## Как это работает

- `scripts/background.js` — сервис-воркер: правила DNR, инъекция отпечатков, замер памяти,
  бейдж, динамическая регистрация heartbeat-скрипта.
- `scripts/anon-profiles.js` — профили стран/платформ и два самодостаточных скрипта для
  MAIN world (`applyTabStealth` / `restoreTabStealth`), которые откатывают все патчи.
- `scripts/vkpoints-bg.js` — модуль автосбора баллов (IIFE), подключается из воркера;
  обмен с попапом через `chrome.runtime` сообщения `vkpoints:*`.
- `scripts/defaults.js` — дефолты настроек, слияние и утилиты.
- `popup/` — панель с 4 вкладками; `options/` — страница настроек; `vkpoints/` — content-скрипт
  и страница статистики.
- content-скрипт `vkpoints/content.js` внедряется статически (manifest) и динамически
  (для вкладок, открытых до перезагрузки расширения).

## Разрешения

| Разрешение | Зачем |
|---|---|
| `tabs`, `activeTab`, `scripting` | список/закрытие вкладок, инъекция скриптов |
| `storage` | настройки и статистика баллов |
| `clipboardWrite` | кнопка «Копировать» в экстракторе ссылок |
| `declarativeNetRequestWithHostAccess` | подмена заголовков (DNR `modifyHeaders`) |
| `alarms` | watchdog сбора баллов, периодический замер памяти |
| `webRequest` | перехват `Authorization`-токена VK |
| `processes` | расход памяти по вкладкам |
| `notifications` | уведомления о сборе баллов |
| `downloads` | бэкап статистики в файл |
| `optional_host_permissions: *://*/*` | отпечатки, память и ссылки на любых сайтах (по согласию) |
| `host_permissions` (vkvideo, twitch) | работа модуля баллов |

## Структура

```
manifest.json          — манифест MV3
icons/                  — иконки
popup/                  — панель (popup.html/css/js)
options/                — страница настроек (options.html/css/js)
scripts/
  background.js         — сервис-воркер: DNR, отпечатки, память, бейдж
  anon-profiles.js      — профили стран + MAIN-world скрипты
  vkpoints-bg.js        — модуль автосбора баллов
  defaults.js           — дефолты и утилиты
  heartbeat.js          — heartbeat-пинг при просмотре страниц
vkpoints/
  content.js            — определение канала/капча токена/клик Twitch
  stats.html/.css/.js   — страница статистики с графиками
```

## Ограничения

- Chrome/Edge/Opera/Brave/Yandex (Manifest V3). Firefox не поддерживается.
- Canvas-шум детерминированный (безопасная обфускация, не «рандомизация отпечатка»).
- Точный замер памяти требует доступа ко всем сайтам; без него — приблизительная оценка.

## Дисклеймер

Анонимайзер и автосбор баллов могут противоречить пользовательским соглашениям
соответствующих платформ. Проект создан в образовательных целях (демонстрация MV3:
`declarativeNetRequest`, MAIN-world инъекция, сервис-воркер, `chrome.processes`).
Используйте на свой страх и риск.
